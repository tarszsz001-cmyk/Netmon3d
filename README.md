# Netmon Android

แอป Android ห่อหน้า /m ของ netmon3d (WebView) เก็บที่อยู่เซิร์ฟเวอร์ไว้ในเครื่อง ไม่มี IP/ชื่อ/รูปของออฟฟิศในโค้ดนี้

## สร้างไฟล์ APK ด้วย GitHub Actions
1. สร้าง repo ใหม่บน GitHub (แนะนำ Private) แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (รวมโฟลเดอร์ .github)
2. แท็บ Actions -> Build APK -> Run workflow (หรือรอให้รันอัตโนมัติหลัง push)
3. เสร็จแล้วเปิดรันนั้น ดาวน์โหลด artifact "netmon-apk" (เป็น zip) แตกไฟล์จะได้ app-debug.apk
4. ส่งไฟล์เข้ามือถือ Android แล้วกดติดตั้ง (ต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

## สร้างเองด้วย Android Studio
เปิดโฟลเดอร์นี้ -> Build -> Build APK(s)

## ใช้งาน
เปิดแอปครั้งแรกใส่ที่อยู่ เช่น 192.168.1.50:8090 หรือ 100.x.x.x:8090 (Tailscale) แล้วล็อกอิน
ปุ่ม ⚙ มุมขวาล่างใช้เปลี่ยนที่อยู่เซิร์ฟเวอร์
